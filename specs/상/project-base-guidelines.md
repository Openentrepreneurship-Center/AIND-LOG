## 개요
"Backend" 프로젝트는 교통카드 시스템의 백엔드이다.
Spring Boot 3.2.4, MyBatis 3.0.3, WebClient 기반으로 한 고품질 백엔드 개발을 위한 패턴과 원칙을 제공합니다.


## 개발 환경
### 기술 스택
- **JDK**: 17
- **IDE**: VsCode IDE
- **LLM 도구**: Cline
- **빌드 도구**: Maven 3.9
- **데이터베이스**: PostgreSQL 17
- **API 문서**: Swagger/OpenAPI 3
- **Spring Boot**: 3.2.4
- **Mybatis**: 3.0.3
