## 핵심 비즈니스 규칙 구현 규칙
* [ ] **프로그램 ID**(PGM-XXX)를 항상 메소드 주석에 작성한다.
* [ ] 핵심 비즈니스 규칙의 **RULE ID**들을 모두 메소드 주석에 작성한다.
* [ ] 핵심 비즈니스 규칙의 **RULE ID**들을 메소드의 line 주석에 작성한다.
* [ ] **프로그램 ID**와 **RULE ID** 주석은 삭제하지 않는다.
* [ ] 모든 **RULE ID**에 대해 구현이 완료되었는지 검토한다.
* [ ] 구현한 소스에 lint 에러 등 오류가 없는지 점검한다.
